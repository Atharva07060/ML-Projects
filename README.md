# Machine Learning Projects

A collection of machine learning projects with data preparation, model evaluation, and interactive dashboards.

## Projects

### California Housing Price Prediction
A regression project that explores California district-level housing data, compares models, and estimates median house values with a Flask dashboard.

See [`California_Housing_Price_Prediction/README.md`](California_Housing_Price_Prediction/README.md) for the dataset, results, and setup instructions.

### Social Network Ads Purchase Prediction
A classification project that predicts whether a customer purchased an advertised product and presents the results in a Flask dashboard.

See [`Social_Network_Ads_Dashboard/README.md`](Social_Network_Ads_Dashboard/README.md) for details.

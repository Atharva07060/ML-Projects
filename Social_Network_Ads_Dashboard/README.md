# Social Network Ads Purchase Prediction

A small machine learning project that explores the Social Network Ads dataset, compares classification models, and serves purchase predictions through a Flask dashboard.

## Project overview

The dashboard lets you explore the customer data, view the model comparison, and enter a customer's age, estimated salary, and gender to get a purchase prediction. The training script handles data cleaning, exploratory analysis, model training, and report generation.

## Dataset

The dataset contains 400 customer records and these columns:

| Column | Description |
| --- | --- |
| `User ID` | Customer identifier; excluded from training |
| `Gender` | Customer gender |
| `Age` | Customer age in years |
| `EstimatedSalary` | Estimated annual salary |
| `Purchased` | Target: `0` for no purchase, `1` for purchase |

The target is moderately imbalanced: 257 customers did not purchase and 143 did. There are no missing values in the supplied file. Ages range from 18 to 60, and estimated salaries range from 15,000 to 150,000. `User ID` is left out of the model because it identifies a row rather than describing a customer.

## Findings

Age and estimated salary show useful separation between the purchase groups in the exploratory plots, though neither feature alone perfectly separates them. The dataset is small, so the model results should be treated as an educational comparison rather than an estimate of real-world campaign performance.

Five classifiers are compared: Logistic Regression, K-Nearest Neighbors, Decision Tree, Random Forest, and Support Vector Machine. The selected model is the Decision Tree, based on its highest mean five-fold cross-validation F1 score (0.890) on the training data.

On the held-out test set, the Decision Tree reached 89.0% accuracy, 0.853 F1, and 0.939 ROC AUC. Other models scored higher on some test metrics; for example, the Support Vector Machine had the highest test F1 (0.880). The model choice follows cross-validation results, while the dashboard and reports show the full comparison.

## Setup and run on Windows

Open PowerShell in the project folder and run:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python train.py
python app.py
```

If PowerShell prevents virtual environment activation, allow it for the current terminal session and activate again:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

When Flask starts, open [http://127.0.0.1:5000](http://127.0.0.1:5000). The `/health` endpoint reports whether the model and reports are ready. Stop the server with `Ctrl+C`.

## Data preparation and evaluation

The training script removes duplicate rows, normalizes gender values, converts numeric columns, and drops rows with an invalid target. Missing numeric features are median-imputed and missing gender values are filled with the most common value by the fitted preprocessing pipeline. Numeric features are scaled, and gender is one-hot encoded.

A stratified 75/25 train/test split is used. Models are compared using five-fold cross-validation F1 on the training split and accuracy, precision, recall, F1, and ROC AUC on the held-out test split. The saved model includes preprocessing, so the same transformations are applied to dashboard predictions.

## Notes

- The dataset is a small sample and does not establish how the model would perform on new advertising audiences.
- The prediction probability is a model estimate, not a guarantee.
- Interactive charts use Plotly from a public CDN and need an internet connection. Flask predictions run locally.
- The app listens on `127.0.0.1` by default.
